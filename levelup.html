Nivelamento

Upando level 1 - 30

  • Lembre-se de estar usando set TK ou arbomon.
  • Lembre-se de estar usando yellow soccer 1000% exp.
  • Lembre-se de estar usando magnetic card 1800% exp.
  • Lembre-se de ativar os dois buffs de 1000% exp.
  • É recomendado que o nível do digimon seja menor que 30.
  • Derrote Blossomon até chegar no nível 30.

Upando level 30 - 47

  • Lembre-se de estar usando set TK ou arbomon.
  • Lembre-se de estar usando yellow soccer 1000% exp.
  • Lembre-se de estar usando magnetic card 1800% exp.
  • Lembre-se de ativar os dois buffs de 1000% exp.
  • É recomendado que o nível do digimon seja 30.
  • Derrote Rockmon e Woodmon até chegar no nível 47.

Upando level 47 - 81

  • Lembre-se de estar usando set TK ou arbomon.
  • Lembre-se de estar usando yellow soccer 1000% exp.
  • Lembre-se de estar usando magnetic card 1800% exp.
  • Lembre-se de ativar os dois buffs de 1000% exp.
  • É recomendado que o nível do digimon seja 51.
  • Derrote Zudomon e Silphymon até chegar no nível 51.
  • Derrote Archnemon até chegar no nível 61.
  • Derrote Argomon, Pilevolcamon e Grandiskuwagamon até chegar no nível 71 ou 81.

Upando level 71 - 103

  • Lembre-se de estar usando set TK ou arbomon.
  • Lembre-se de estar usando yellow soccer 1000% exp.
  • Lembre-se de estar usando magnetic card 1800% exp.
  • Lembre-se de ativar os dois buffs de 1000% exp.
  • É recomendado que o nível do digimon seja 71.
  • Derrote Carta de Monstro Nível Superior Lv 1 até chegar no nível 103.

Upando level 103 - 140

  • Lembre-se de estar usando set TK ou arbomon.
  • Lembre-se de estar usando yellow soccer 1000% exp.
  • Lembre-se de estar usando magnetic card 1800% exp.
  • Lembre-se de ativar os dois buffs de 1000% exp.
  • É recomendado que o nível do digimon seja 103.
  • Derrote qualquer digimon até chegar no nível 140.

Upando level 81 - 140

  • Lembre-se de estar usando set TK ou arbomon.
  • Lembre-se de estar usando yellow soccer 1000% exp.
  • Lembre-se de estar usando magnetic card 1800% exp.
  • Lembre-se de ativar os dois buffs de 1000% exp.
  • É recomendado que o nível do digimon seja 81.
  • Derrote Makuramon no último mapa da dungeon do gato até chegar no nível 140.
